- The `cursor.com/install` script requires `bash`, which alpine does not ship — `bash` is in the runtime `apk add` list. Do not remove it.
- The pre-commit hook runs Cursor Agent and can stage unrelated files / leave stash conflict markers. Before committing, run `git status` and `git checkout HEAD -- <unrelated file>` for anything the hook polluted, then commit only your intended files.
- `vp run test` has a repo-wide pre-existing vitest suite-collection failure (`Vitest failed to find the current suite` / `Cannot read properties of undefined (reading 'config')`), reproducible on the base SHA. It is environmental. The `credentialBindMounts` unit tests collect and pass. Do not treat it as a regression.
